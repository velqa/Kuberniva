Kuberniva 0.7.0 rebuilds the Argo CD graph around what is failing, adds live Pod logs to Argo CD, and makes text much clearer, especially in dark mode.

## ✨ What's new

**Argo CD graph that shows what is happening**
- Every resource shows its **health** (Healthy, Progressing, Degraded, Suspended, Missing) and **sync** status as icons, like the Argo CD dashboard
- Failing resources are drawn in red with their reason, such as **CrashLoopBackOff** or a Deployment's progress-deadline message
- A failure deep in the tree is carried up to its owners: a Deployment shows **1 failing below** even when Argo CD calls it healthy, and the path from the Application to the failure is drawn as a red, animated line
- Pods show one square per container (green ready, red not ready) and a restart count
- A filter bar counts resources by health and sync; **Problems** dims everything except failures and the path to them
- A failure list above the graph, worst first, jumps to and highlights each failing resource; the graph opens on the first failure
- Zoom in and out, **Fit** the whole tree, drag to pan, and ⌘ + scroll to zoom; failing children are always shown before healthy ones, so a collapsed "+N more" never hides a failure

**Live Pod logs in Argo CD**
- Clicking a Pod in the graph opens its logs in a panel right in the Argo CD view, streaming live as the container writes
- Pick the container, follow new lines (scroll up to pause), reload, or open the full log view

**Clearer text**
- New typefaces: Inter for the interface and JetBrains Mono for names, logs, and code, both built for small sizes on screen
- The default interface size is now 100%; the old 90% default rendered text at fractional sizes, which made it look soft. You can still change it with **−** and **+** in the status bar, or reset it with ⌘0
- The smallest labels are larger throughout
- Dark mode uses a cool graphite palette in the spirit of Lens, with white primary text and brighter secondary text

## 🛠 Fixes

- Making the window smaller pushed the **Age** and **Memory** columns (and others) off the side of tables; columns now shrink together so every column stays visible, from the smallest window up
- Helm and OCM hub lists keep just the name and status while a release or cluster is open beside them, so nothing is cut off

## 🔄 Updating

- **In the app:** **Kuberniva → Check for Updates…**, or **Settings → Check for updates → Download and install → Restart now**
- **With Homebrew:** `brew upgrade --cask --greedy kuberniva`
- **New install:** `brew install --cask velqa/tap/kuberniva`, or download the DMG below
