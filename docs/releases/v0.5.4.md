Kuberniva 0.5.4 makes every page live, shows the columns you know from kubectl, and brings a new dark theme.

## ✨ What's new

**Live everywhere**
- The Overview, Events, and Argo CD now update the moment something changes, using the same live engine as Pods: one snapshot, then changes streamed in small batches
- Node health and capacity update instantly; CPU and memory refresh every 15 seconds
- New events appear as they happen; Argo CD sync and health change in place
- A green **Live** badge shows when a page is fully loaded and streaming; amber means it is reconnecting

**More columns**
- Lists show the same columns as `kubectl get`, straight from the cluster: **Type**, **Cluster-IP**, **External-IP**, and **Ports** for Services; **Ready**, **Up-to-date**, and **Available** for Deployments; **Completions** for Jobs; **Schedule** for CronJobs; and printer columns for custom resources
- Columns update live and are included in search, so typing **LoadBalancer** finds those Services

**Resizable layout**
- Drag the edge of the **Name** column in Workloads and Resources to see long names in full; double-click to reset
- The Logs page and Argo CD's ApplicationSets and Projects have a draggable divider between the list and the details
- All sizes are remembered

**Dark theme**
- A new layered dark palette: a deeper background, clearly separated panels, crisper borders, and brighter secondary text
- Status colors, badges, tabs, and buttons are tuned for dark backgrounds
- Every page was checked for text contrast in both themes; light mode's gray labels are easier to read too

## 🔄 Updating

- **In the app:** **Settings → Check for updates → Download and install → Restart now**
- **With Homebrew:** `brew upgrade --cask --greedy kuberniva`
- **New install:** `brew install --cask velqa/tap/kuberniva`, or download the DMG below

Runs natively on Apple Silicon and Intel Macs. Signed with an Apple Developer ID and notarized by Apple.
