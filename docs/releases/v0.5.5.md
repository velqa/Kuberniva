Kuberniva 0.5.5 makes CPU and memory move in real time and makes every table column resizable.

## ✨ What's new

**Real-time metrics**
- The Overview checks for new CPU and memory samples every 3 seconds and updates the moment metrics-server publishes one, with no wasted redraws in between
- Numbers and bars glide to each new value instead of jumping
- The Nodes table shows how fresh the numbers are, for example **Metrics 4s ago · metrics-server samples every ~15s**, with a pulse when a new sample arrives
- Pod CPU and memory on the Workloads page refresh every 10 seconds instead of every minute

**Resizable columns**
- Every column in Pods, Workloads, Resources, the Overview's node table, and Argo CD's application list can be dragged wider or narrower; double-click a column edge to reset it
- Widths are remembered separately for each kind (Pods, Deployments, Services…)
- When columns no longer fit, Workloads tables scroll sideways; in other lists the remaining columns shrink to make room

**Workloads**
- **Pods** is now the first tab and opens by default

## 🛠 Fixes

- Column edges were hard to grab (about 3 px wide) and only the Name column could be resized
- Table headers drifted out of line with their rows by a few pixels per column

## 🔄 Updating

- **In the app:** **Settings → Check for updates → Download and install → Restart now**
- **With Homebrew:** `brew upgrade --cask --greedy kuberniva`
- **New install:** `brew install --cask velqa/tap/kuberniva`, or download the DMG below

Runs natively on Apple Silicon and Intel Macs. Signed with an Apple Developer ID and notarized by Apple.
