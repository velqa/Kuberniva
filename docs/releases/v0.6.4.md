Kuberniva 0.6.4 makes logs easier to read, moves favorites to the top bar, and keeps Delete out of the way.

## ✨ What's new

**Readable logs**
- Multi-line output now reads as one entry with one timestamp: pretty-printed dicts, lists, tuples, JSON, YAML-style blocks, and stack traces no longer break into separate lines
- Times are shown as a short, fixed-width local time (hover for the full timestamp), so entries line up and continuation lines stay indented under their message
- A new **JSON** button expands single-line JSON objects and Python dicts into indented form
- Search counts and matches whole entries

**Favorites in the top bar**
- Favorite clusters moved from the sidebar to the top bar, beside the cluster and namespace pickers
- Each favorite has its own color, two-letter initials, and its ⌘ number, so they are easy to tell apart; names appear when there is room
- Click to switch, right-click to rename or remove, and ★ opens the full favorites list

**Delete moved to ⋯**
- When an object is open, **Delete** now lives in the **⋯ More actions** menu next to the close button, together with **Copy name** and **Copy namespace/name**
- Applies to workloads, resources, and the ConfigMap and Secret editors; deleting still asks for confirmation twice

## 🛠 Fixes

- In dark mode, hovering **View logs** or **Terminal** turned the card white with white text; it now highlights readably
- The shell now uses the same text size as logs, and its output fills the panel
- **View logs** and **Terminal** were taller in dark mode than in light mode; both themes now use the same compact size, and scrollbars take the same space in both

## 🔄 Updating

- **In the app:** **Kuberniva → Check for Updates…**, or **Settings → Check for updates → Download and install → Restart now**
- **With Homebrew:** `brew upgrade --cask --greedy kuberniva`
- **New install:** `brew install --cask velqa/tap/kuberniva`, or download the DMG below

Runs natively on Apple Silicon and Intel Macs. Signed with an Apple Developer ID and notarized by Apple.
