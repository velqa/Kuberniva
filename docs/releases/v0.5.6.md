Kuberniva 0.5.6 makes column resizing feel right, keeps the Overview moving, and polishes dark mode menus.

## ✨ What's new

**Column resizing that follows your mouse**
- A column edge now tracks the pointer exactly, at every interface size
- Columns to the left stay put while you drag; only columns to the right give up space
- Every table (Pods and other workloads, Resources, the Overview's nodes, and Argo CD) scrolls sideways when columns no longer fit, instead of stopping the drag
- Drags are smooth even on large lists

**Overview metrics**
- Kuberniva learns how often your metrics-server really publishes samples and shows it, for example **new samples about every 60s**
- When a sample is late, the label turns amber and says **waiting for metrics-server**, so a slow metrics-server never looks like a frozen app

## 🛠 Fixes

- Column drags started from a stale width and ran ahead of the pointer
- Column edges in Resources, the Overview, and Argo CD lagged behind the pointer as other columns shrank
- The Overview could stall for a long time when the Metrics API was slow; nodes now load first and metrics follow
- In dark mode, the selected cluster in the cluster menu was white on white; the menu, search box, Reveal button, favorite stars, and section badges now use the dark palette
- Small text in the light theme's search window and cluster tiles is easier to read

## 🔄 Updating

- **In the app:** **Settings → Check for updates → Download and install → Restart now**
- **With Homebrew:** `brew upgrade --cask --greedy kuberniva`
- **New install:** `brew install --cask velqa/tap/kuberniva`, or download the DMG below

Runs natively on Apple Silicon and Intel Macs. Signed with an Apple Developer ID and notarized by Apple.
