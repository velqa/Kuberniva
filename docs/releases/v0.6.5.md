Kuberniva 0.6.5 adds a favorites rail, searches logs in place, and keeps long log lines on one line.

## ✨ What's new

**Favorites rail**
- Favorite clusters now live in a slim rail on the edge of the window, always one click away, even with the sidebar hidden
- Each cluster is a colored circle with its initials and ⌘ number; it rounds into a square on hover, and the active cluster gets a ring and an edge bar
- Hover a cluster for a name tag with its status and shortcut; right-click to rename or remove it, and **+** opens the favorites list
- Flip the rail to the other side of the window with the ⇄ button, or choose **Left**, **Right**, or **Off** in **Settings → Favorites**

**Log search that points, not filters**
- Searching logs now highlights every match in place and keeps all lines visible, so you see each match in context
- Step through matches with **↑** and **↓** or ↩ and ⇧↩; the counter shows where you are, for example **3/100**, and the view scrolls to the current match

**Long log lines**
- A single-line log entry stays on one line, and the log view scrolls sideways; dicts, lists, and stack traces keep their own indented layout

## 🔄 Updating

- **In the app:** **Kuberniva → Check for Updates…**, or **Settings → Check for updates → Download and install → Restart now**
- **With Homebrew:** `brew upgrade --cask --greedy kuberniva`
- **New install:** `brew install --cask velqa/tap/kuberniva`, or download the DMG below

Runs natively on Apple Silicon and Intel Macs. Signed with an Apple Developer ID and notarized by Apple.
