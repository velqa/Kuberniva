Kuberniva 0.6.6 makes updates harder to miss, Delete easier to find, and Secret editing safer.

## ✨ What's new

**Updates that find you**
- Kuberniva checks for a new version every hour, and also when you come back to the window after a while, even if it sat in the background or the Mac slept
- When one is out, the update window opens on its own with the release notes and asks whether to update now
- **Later** keeps the reminder quiet for 6 hours, then asks again; an **Update to X.Y.Z** button stays in the top bar until you install it

**Cleaner Pod and Deployment views**
- The API version (such as `v1` or `apps/v1`) is no longer shown under the Pod and Deployment headers or in the Pod details

## 🛠 Fixes

- The **Delete** button that appears when you select Pods or other objects was faint, especially in dark mode; it is now a clear red button with a trash icon in both themes, and **Delete** in the **⋯** menu is easier to read in dark mode
- Editing a Secret while its values were hidden saved plain text where base64 was expected, so that key no longer decoded correctly. Hidden values are now read-only with a **Reveal to edit** button, edits are always made as plain text and encoded on save, and Save stops with a clear message if a value is not valid base64

## 🔄 Updating

- **In the app:** **Kuberniva → Check for Updates…**, or **Settings → Check for updates → Download and install → Restart now**
- **With Homebrew:** `brew upgrade --cask --greedy kuberniva`
- **New install:** `brew install --cask velqa/tap/kuberniva`, or download the DMG below

Runs natively on Apple Silicon and Intel Macs. Signed with an Apple Developer ID and notarized by Apple.
