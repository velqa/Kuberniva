Kuberniva 0.5.3 stays connected in the background, finds objects by status, and shows release notes properly.

## ✨ What's new

**Background updates**
- Live lists keep streaming while Kuberniva is in the background, minimized, or behind other apps
- On macOS, closing the window keeps Kuberniva running, like other Mac apps. Click the Dock icon to return to the same view, or quit with **⌘Q**

**Waking from sleep**
- Kuberniva detects when your Mac wakes and quietly resumes every live list where it left off, without reloading it
- The Overview and Events refresh in the background with no banner

**Search by status**
- Search in Workloads, Resources, Events, and Argo CD matches status too, in any letter case: type **failed**, **pending**, or **running** to see only those objects
- Combine words to narrow further, for example **failed team-01**
- Resource lists have their own search box
- **Select all** selects only the objects the search shows, so cleaning up failed Pods can't touch anything else

**Update notes**
- **Settings → Check for updates** shows what's new with headings, categories, and bullet points, the same way GitHub does

## 🛠 Fixes

- Switching to another app and back no longer reconnects to the cluster or shows **Checking your connection…**. Kuberniva only reconnects when a connection actually fails
- The Overview's one-minute refresh no longer flashes a loading message
- After a network change, live lists reconnect right away instead of waiting for a stalled connection to time out
- Update notes no longer show raw formatting characters such as `**`

## 🔄 Updating

- **In the app:** **Settings → Check for updates → Download and install → Restart now**
- **With Homebrew:** `brew upgrade --cask --greedy kuberniva`
- **New install:** `brew install --cask velqa/tap/kuberniva`, or download the DMG below

Runs natively on Apple Silicon and Intel Macs. Signed with an Apple Developer ID and notarized by Apple.
