Kuberniva 0.5.0 brings Argo CD, Gateway API, and Admission Policies into the workspace, and stays fast on large clusters.

## ✨ What's new

**Argo CD**
- Appears in the sidebar automatically when Argo CD is installed
- A dashboard with application counts, a **Needs attention** filter, and sync and health for every application
- Details for each application: source, destination, sync policy, last sync, conditions, and managed resources
- **Refresh** and **Sync**, each after a confirmation

**Gateway API**
- Gateway APIs have their own sidebar group
- Gateways show their class, addresses, status, listeners with attached-route counts, and the routes attached to them
- HTTPRoutes and GRPCRoutes show hostnames, each parent Gateway's verdict, and rules with matches, filters, and weighted backends
- Services list the Gateway API routes that send traffic to them, grouped by Gateway

**Admission Policies**
- A dedicated sidebar group when the cluster serves them
- ValidatingAdmissionPolicy, MutatingAdmissionPolicy, and their bindings show properties, matched resources, match conditions, variables, validations, mutations, and audit annotations
- CEL expressions are highlighted in light and dark themes, with type-checking warnings from the API server

**Large clusters**
- Long lists render in batches as you scroll; selecting all 3,000 Pods went from 682 ms to 36 ms
- Live updates are throttled on busy clusters, watches start from the current state, and non-Pod lists transfer only metadata

**Connection & sign-in**
- A compact connection pill in the top bar: **Checking your connection…** after waking, **Reconnect** when needed, and **Recovery paused** while you edit
- SSO clusters (OIDC `exec` or auth provider) wait up to five minutes so a browser sign-in after a token expires is not cut off
- Every cluster read has a time limit, so an unreachable server can't leave a page loading forever

**Overview, Events & Workloads**
- The Overview leads with health: nodes ready, CPU, memory, and node problems, then every node in one table
- Events are grouped by the object they describe, with warnings first
- Workload details and logs open in focus mode, with colored log lines for timestamps, warnings, and errors

## 🛠 Fixes

- Leaving Workloads or Resources mid-load no longer stops those pages from loading again
- Error notifications are clearly marked and stay visible longer

## 🔄 Updating

- **In the app:** **Settings → Check for updates → Download and install → Restart now**
- **With Homebrew:** `brew upgrade --cask --greedy kuberniva`
- **New install:** `brew install --cask velqa/tap/kuberniva`, or download the DMG below

Runs natively on Apple Silicon and Intel Macs. Signed with an Apple Developer ID and notarized by Apple.
