Kuberniva 0.5.2 makes live lists fast and dependable, even on large and busy clusters.

## ✨ What's new

**Live resources**
- Lists update in place as objects are added, changed, or deleted, without reloading the whole list
- Each list starts from one consistent snapshot, read in pages, and continues exactly where it left off after a reconnect
- Bursts of changes are applied in small batches, so thousands of Pods stay smooth
- A late deletion can never remove a newer object that reused the same name
- Pod CPU and memory refresh separately every minute and are kept between updates
- Open details refresh on their own when the object changes
- When your role can list but not watch a resource, the list refreshes every 30 seconds instead of freezing

**Workloads layout**
- Drag the bar between the workload list and the details or logs to resize them; the width is remembered
- The bar also works with the keyboard (←, →, Home, End), and a double-click resets it
- The list shows more columns as it gets wider: Name and Status, then Ready, Restarts, and Age, then everything

## 🛠 Fixes

- Pod metrics no longer wait indefinitely while an SSO sign-in is pending

## 🔄 Updating

- **In the app:** **Settings → Check for updates → Download and install → Restart now**
- **With Homebrew:** `brew upgrade --cask --greedy kuberniva`
- **New install:** `brew install --cask velqa/tap/kuberniva`, or download the DMG below

Runs natively on Apple Silicon and Intel Macs. Signed with an Apple Developer ID and notarized by Apple.
