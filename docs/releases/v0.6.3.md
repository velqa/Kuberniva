Kuberniva 0.6.3 fixes a crash when opening logs and removes the name from the window's title bar.

## 🛠 Fixes

- Opening a Pod's logs in 0.6.2 closed the app. Live log streaming now starts safely, and if a stream cannot connect, the log view shows **Connecting…** and retries instead of failing
- The window's title bar no longer shows the app name; it still appears in the Dock, the menu bar, and Mission Control

## 🔄 Updating

- **In the app:** **Kuberniva → Check for Updates…**, or **Settings → Check for updates → Download and install → Restart now**
- **With Homebrew:** `brew upgrade --cask --greedy kuberniva`
- **New install:** `brew install --cask velqa/tap/kuberniva`, or download the DMG below

Runs natively on Apple Silicon and Intel Macs. Signed with an Apple Developer ID and notarized by Apple.
