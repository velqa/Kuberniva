Kuberniva 0.5.1 turns Argo CD into a full application workspace and makes containers without a shell easy to work with.

## ✨ What's new

**Argo CD applications**
- Opening an application shows a full page with its **health**, **sync status**, and **last sync** at a glance
- **Overview**: what needs attention, the source (Helm chart, Kustomize overlay, or path) with parameters and value files, the destination and sync options, images, and links
- **Resources**: a tree of every managed resource grouped by kind, with health and sync status, filters for out-of-sync, unhealthy, and needs-prune, and live Pods under each Deployment, StatefulSet, or DaemonSet
- **Last sync**: the phase, duration, revision, who started it, and the result for every resource
- **History**: every deployment with its revision and author, and **Roll back** to any earlier one
- **Events**: Kubernetes events for the application

**Argo CD actions**
- **Sync** now lets you choose a revision and **Prune**, **Dry run**, **Apply out-of-sync only**, or **Force**
- Sync a single resource from the resource tree
- Turn **auto-sync** on or off, with self-heal and prune
- **Terminate** a running sync
- Every action asks for confirmation first

**Argo CD dashboard**
- **ApplicationSets** and **Projects** have their own tabs
- Works with namespace-scoped access: when you can't list across all namespaces, Kuberniva shows the selected namespace, then `argocd`, and says so

**Pod terminal**
- Detects which shell the container ships (bash, sh, BusyBox, ash)
- **No shell** runs a program directly in distroless images, for example `/app/server --version`
- **Debug container** attaches an ephemeral container that can see the target's processes. Choose the image once; air-gapped clusters can use one from their internal registry
- Commands report non-zero exit codes

**Workload & Pod details**
- Key facts (status, ready, restarts, CPU, memory, age) appear as tiles, with node, namespace, and API in one row
- Diagnostics, containers, and configuration use larger, easier-to-read text in matching cards

## 🛠 Fixes

- Overview CPU and memory are rounded: **21%** and **2.24 cores** instead of raw values like 2.2362309125 or 2236230912n
- Memory and storage read as **14.6Gi**, including node capacity and allocation

## 🔄 Updating

- **In the app:** **Settings → Check for updates → Download and install → Restart now**
- **With Homebrew:** `brew upgrade --cask --greedy kuberniva`
- **New install:** `brew install --cask velqa/tap/kuberniva`, or download the DMG below

Runs natively on Apple Silicon and Intel Macs. Signed with an Apple Developer ID and notarized by Apple.
